# 教程：把视频做成 Apple Watch 动态表盘

> **开始之前，请先看 [README 里的「先看这里：能不能用？」](../README.md#先看这里能不能用)**：只在 Series 11 46mm + watchOS 27 上验证过，没有 Mac 无法安装。

从零开始，到手表上的系统表盘播放你的高清循环动画，大约需要 30–60 分钟。第一次连接手表最花时间。

## 1. 你需要准备

- 一台 Mac，安装 **Xcode 27** 或更新版本。
- 一块 Apple Watch，**watchOS 27**。版式按 **Series 11 46mm**（416×496 像素）调好；其他尺寸也能装，但画面裁切和时间位置要自己调（见 [第 9 步](#9-自定义)）。
- 和手表配对的 iPhone，以及一根能连 Mac 的数据线。
- 一个 Apple ID。免费账号就能装，只是签名 **7 天后过期**，到期重新安装一次即可。
- 仓库已经自带 80 帧动画（取自 P3R 官网开场视频，仅供作业），**不需要另外准备视频**。想换成自己的视频时才需要，见第 3 步。

## 2. 获取代码

```sh
git clone https://github.com/Hastur-02/P3R-LiveClock.git P3R-LiveClock
cd P3R-LiveClock
```

## 3. （可选）换成你自己的视频

`media/` 里已经有现成的动画帧，**不换视频就直接跳到第 4 步**。

想换视频的话，最好是：

- 首尾能无缝衔接的循环片段，5–7 秒；
- 画面一侧留有大块深色或纯色区域，用来放时间。

把视频放进 `assets/`，然后重新生成帧（会覆盖 `media/` 里的默认帧）：

```sh
cp ~/Downloads/你的视频.mp4 assets/background.mp4
swift scripts/prepare_frames.swift assets/background.mp4 media
```

脚本只用 macOS 自带的 AVFoundation，不需要安装 ffmpeg。完成后 `media/` 里会出现：

- `p3r-0000.png` … 若干张动画帧，每张 416×600 像素；
- `poster-retina.png`：预热用的静帧；
- `frames.json`：帧数、时长等参数。

### 调整取景和帧率

脚本从横屏视频里截取一条竖条，宽高比和手表屏幕一致。两个参数可以用环境变量调整：

| 变量 | 默认 | 作用 |
|---|---|---|
| `CROP_X` | `180` | 竖条左边缘在原片里的位置（像素，按 1920×1080 计）。往右挪就增大 |
| `FPS` | `12` | 动画帧率。帧数 = 时长 × 帧率 |

```sh
CROP_X=600 FPS=10 swift scripts/prepare_frames.swift assets/background.mp4 media
```

**帧数越多，系统表盘进程里占的内存越大**：80 帧解码后约 80 MB。这是动画偶尔卡住的主要压力来源（见 [原理](原理.md)）。如果你的手表经常卡，可以把帧率降到 8–10，或者截一段更短的循环。

## 4. 用 Xcode 打开并设置签名

```sh
open LiveClock.xcodeproj
```

工程里有两个 target：

| target | 用途 |
|---|---|
| **LiveClock** | 手表 App，复杂功能都在这里。**要装的是它** |
| P3RPhone | iPhone 配套 App，可选。免费签名下不能经由它安装到手表，可以不管 |

### 4.1 填开发团队

1. 左侧点工程「LiveClock」→ TARGETS 选 **LiveClock** → 打开 **Signing & Capabilities** 页签。
2. **Team** 选你的 Apple ID（显示为「你的名字 (Personal Team)」）。还没登录的话，先在 Xcode → Settings → Accounts 里添加。

### 4.2 改成你自己的 bundle id

仓库里用的是占位符 `com.example.p3rliveclock`，免费账号通常注册不了，要改成独一无二的，比如把 `example` 换成你的名字。**三处要一起改，前缀保持一致**：

| 位置 | 改成 |
|---|---|
| LiveClock target → Bundle Identifier | `com.你的名字.p3rliveclock.watchkitapp` |
| P3RPhone target → Bundle Identifier | `com.你的名字.p3rliveclock` |
| `Info.plist` 里的 `WKCompanionAppBundleIdentifier` | `com.你的名字.p3rliveclock` |

改完后 Signing 页签不再报错，就说明签名准备好了。

## 5. 让 Xcode 连上手表

第一次连接最容易卡住，请按顺序做。

### 5.1 iPhone

1. 用数据线把 iPhone 连到 Mac，在手机上点「信任这台电脑」。
2. iPhone：设置 → 隐私与安全性 → **开发者模式** → 打开，按提示重启。

### 5.2 手表

1. 手表戴在手上、解锁，靠近 iPhone 和 Mac。
2. 在 Xcode 里打开设备窗口：顶部运行目标下拉菜单 → **Manage Run Destinations…**（也可以按 ⇧⌘2）。选中 iPhone，等一两分钟，手表会出现在列表里。
3. 手表上：设置 → 隐私与安全性 → **开发者模式** → 打开，重启手表。
   - 这个开关要在手表**被 Xcode 发现过一次之后**才会出现。重装过手表系统之后也会重新隐藏。
4. 按屏幕提示完成配对：手表或 Xcode 会显示一个配对码，在另一边确认或输入。

### 5.3 连接排错

Xcode 能看到手表，但一直显示「Currently Unavailable」或者「无法建立连接」的话，按这几条逐一排查：

| 检查 | 说明 |
|---|---|
| **关掉代理 / VPN** | Xcode 是通过局域网直接连手表的。Mac 上的代理软件（比如开着「系统代理」或 TUN 模式的 Clash、v2rayN、sing-box、Surge）会把这条连接送进代理，导致连不上。|
| **手表蓝牙保持开启** | Mac 要通过蓝牙发现手表，再走 Wi-Fi 连接。关掉蓝牙反而找不到 |
| **同一个 Wi-Fi** | Mac、iPhone、手表连同一个网络，不要用访客网络（访客网络通常隔离设备） |
| **手表保持解锁、亮屏** | 熄屏或锁定时开发连接会断。可以先在手表「设置 → 显示与亮度 → 唤醒时长」里改成 70 秒 |
| **删掉旧配对** | 重装过手表系统的话，在设备窗口里右键旧的手表 → Unpair Device，再重新配对 |

## 6. 安装到手表

1. Xcode 顶部的 scheme 选 **LiveClock**，运行目标选你的手表（不是模拟器）。
2. 按 **⌘R**。第一次要从手表拷贝调试符号，可能要十几分钟，期间保持手表亮屏。
3. 手表提示「不受信任的开发者」的话：iPhone → 设置 → 通用 → **VPN 与设备管理** → 信任你的开发者证书，然后重新运行。
4. 装好后，**在 Xcode 里点停止**（■）。调试器挂着的时候，系统会同步校验复杂功能的时间线，动画可能一直不动；停止调试后就正常了。

## 7. 设置表盘

1. 在手表上打开一次「P3R 动态表盘」App，让系统登记它提供的复杂功能。
2. 回到表盘，**长按** → 左右滑找到「模块化（Modular）」表盘，没有的话滑到最右边点「+」添加。
3. 点 **编辑**，然后左右滑动切换编辑页：
   - **颜色**：选「多色」；
   - **复杂功能**：中央的大矩形槽位选「**P3R 动画研究**」，右下的小圆槽位选「**P3R 玻璃时间**」，**其余槽位都关掉**。
4. 按表冠保存退出。

两个都要设：动画铺满全屏后会盖住系统右上角自带的时间，而右侧那一列竖排时间是由「P3R 玻璃时间」负责画的。

## 8. 日常使用

- **抬腕**时动画循环播放；**放下手腕**（常亮显示）时，系统暂停所有动画、显示静止画面，这是 watchOS 的限制。
- **偶尔先卡几秒到十几秒**：动画要分两步交给表盘，中途断了会停在静帧。App 会在 8 秒内自动补救；如果 App 当时也被系统结束了，后台刷新会在约 30 分钟内补救。
- **一直卡着不动**：打开「P3R 动态表盘」App 就会立即重载；首页也有「手动修复」按钮。**先截一张首页的「最近事件」再操作**，截图能看出卡在哪一步，欢迎附在 issue 里。
- **免费签名 7 天后过期**：表盘会失效，重新做一次第 6 步即可。

## 9. 自定义

### 换视频后调整时间位置

右侧那列时间的位置和字号，是按默认视频右侧的深蓝水面调出来的。换了视频，时间可能会压到画面主体上。参数在 `App/GlassClock.swift` 开头：

| 常量 | 默认 | 含义 |
|---|---|---|
| `big` | 57 | 时、分的字号（点） |
| `small` | 26 | 日期、星期的字号（点） |
| `top` | 100 | 第一行中心的高度（点，屏幕顶端为 0） |
| `right` | 203 | 每行右缘的位置（点，屏幕宽 208） |
| `overlap` | 0.55 | 时、分两行的间距系数，越小压叠得越紧 |
| `cyan` / `shadow` | 水色 / 深蓝 | 文字和影子的颜色 |

时间这个复杂功能的图以屏幕上的 **(172, 216.7) 点**为中心绘制，最大能覆盖约 x 100–208、整个屏幕高度（见 [原理](原理.md#3-时间为什么能画满右侧一整列)）。想把时间放到别处，要相应调整 `slotCenter` 和 `imageSize`。

### 其他尺寸的手表

画面和时间都按 46mm 的 416×496 像素写死。换成 42mm（374×446）等尺寸，需要修改 `scripts/prepare_frames.swift` 里的画布尺寸、`GlassClock.swift` 里的坐标，并在模拟器上核对。欢迎提交适配。

## 10. 在模拟器上试用

没有手表也能先在模拟器里看效果：

```sh
# 建一台 Series 11 46mm 模拟器并启动
xcrun simctl create "LiveClock 46mm" com.apple.CoreSimulator.SimDeviceType.Apple-Watch-Series-11-46mm com.apple.CoreSimulator.SimRuntime.watchOS-27-0
xcrun simctl boot "LiveClock 46mm"

# 编译、安装（模拟器不需要签名）
xcodebuild -project LiveClock.xcodeproj -scheme LiveClock \
  -destination 'platform=watchOS Simulator,name=LiveClock 46mm' -derivedDataPath build build
xcrun simctl install "LiveClock 46mm" build/Build/Products/Debug-watchsimulator/LiveClock.app
```

然后在 Simulator 里按第 7 步设置表盘。模拟器的 watchOS 运行时第一次要从 Xcode 下载（约 4 GB）。

### 调试开关

素材 App 支持几个启动参数，用来在模拟器里验证自动恢复（把 bundle id 换成你自己的）：

```sh
xcrun simctl launch "LiveClock 46mm" com.example.p3rliveclock.watchkitapp -p3rDebug dropFutureArmed=1 refreshSeconds=60
xcrun simctl launch "LiveClock 46mm" com.example.p3rliveclock.watchkitapp -p3rDebug reset
```

| 参数 | 作用 |
|---|---|
| `dropFutureArmed=1` | 丢弃下一次后台的动画请求，人为制造「卡在静帧」 |
| `watchdogSeconds=8` | 看门狗间隔 |
| `refreshSeconds=60` | 后台刷新周期（默认 30 分钟） |
| `staleSeconds=30` | 多久没交过动画就例行重载（默认 1 小时） |
| `reset` | 清除全部调试设置 |

设置后回到表盘，结束 App 和表盘进程（`xcrun simctl terminate "LiveClock 46mm" com.apple.clockface`）就能触发一次后台交接。

## 常见问题

下面没有覆盖到的问题，请按 [README 里的「遇到问题怎么办？」](../README.md#遇到问题怎么办) 去问 AI，不要问主播。

**表盘中央是空白虚线框。**
交接失败了，打开 App 重载一次。如果你换过视频，检查 `media/` 里是否有 `p3r-0000.png`、`poster-retina.png` 和 `frames.json`。

**画面放大了一倍，只看到局部。**
高清动画没拿到 2 倍像素密度。打开 App 重载一次；如果反复出现，请附上首页的事件截图提 issue。

**右上角出现了系统时间。**
中央动画没显示出来，系统时间就露出来了，同上处理。

**时间压到了画面主体上。**
换视频后需要调整 `GlassClock.swift` 的参数，见第 9 步。

**能不能做成真正的系统表盘、出现在表盘列表里？**
不能。watchOS 不开放第三方表盘，这个项目是在系统「模块化」表盘里用复杂功能实现的。
